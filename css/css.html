Design System & CSS Architecture

A reference showcase of the core CSS variables, layout utilities, component classes, and gold accent aesthetics tailored for Atitifor Paul E.'s professional niches.

1. Deep Navy & Gold CSS Root Variables

Centralized CSS custom properties governing color palettes, font stacks, borders, and smooth transitions across all portfolio pages.

:root { /* Primary Aesthetic Theme */ --bg-dark: #0A192F; /* Deep Navy Main Background */ --bg-card: #112240; /* Navy Elevation Card Layer */ --bg-light: #1D2D50; /* Sub-card Container Accent */ /* Gold Accents & Gradients */ --accent-gold: #D4AF37; /* Signature Gold Tone */ --gold-light: #F4E07B; /* Soft Highlight Gold */ --gold-gradient: linear-gradient(135deg, #D4AF37 0%, #F59E0B 100%); /* Typography & Borders */ --text-main: #F8FAFC; /* High contrast text */ --text-muted: #94A3B8; /* Muted body copy */ --border-color: rgba(212, 175, 55, 0.2); --transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1); }
