JavaScript Architecture & Interactive Scripts

Explore the functional scripts powering mobile navigation drawers, dynamic project filtering, modal overlays, and automated service inquiry dispatchers.

1. Mobile Navigation Drawer Handler

Toggles mobile responsive slide-out drawer menus across all pages seamlessly.

// Mobile Navigation Drawer Toggle const mobileToggle = document.getElementById('mobileToggle'); const navLinks = document.getElementById('navLinks'); mobileToggle.addEventListener('click', () => { navLinks.classList.toggle('active'); });

2. Portfolio Category Filter Engine

Filters portfolio items dynamically between Higher Education, CRM & Support, Travel Advisory, and Event Logistics[cite: 2, 3].

// Category Filter Functionality const filterBtns = document.querySelectorAll('.filter-btn'); const portfolioCards = document.querySelectorAll('.portfolio-card'); filterBtns.forEach(btn => { btn.addEventListener('click', () => { filterBtns.forEach(b => b.classList.remove('active')); btn.classList.add('active'); const filter = btn.getAttribute('data-filter'); portfolioCards.forEach(card => { if (filter === 'all' || card.getAttribute('data-category') === filter) { card.style.display = 'flex'; } else { card.style.display = 'none'; } }); }); });

3. Case Study Modal Overlay Controller

Manages popup overlays for detailed executive case studies, preventing background body scrolling when active.

// Modal Open / Close Handlers function openModal(modalId) { document.getElementById(modalId).classList.add('active'); document.body.style.overflow = 'hidden'; } function closeModal(modalId) { document.getElementById(modalId).classList.remove('active'); document.body.style.overflow = 'auto'; }
